GARÇOM VIRTUAL — V29 DEMONSTRAÇÃO — SEM CHAT / SEM IA

Objetivo:
Versão pronta para demonstração online a restaurantes.

Cliente:
- Acessa por QR Code / link da mesa.
- Vê categorias, fotos, preços e disponibilidade.
- Pode abrir Combos.
- Adiciona produtos ao carrinho.
- Pode deixar observação nos itens que aceitam preparo (ex.: X-Salada sem tomate).
- Confirma o pedido e acompanha o status.

Restaurante:
- Recebe a comanda com mesa, itens, quantidades, total e observações.
- Altera status: Novo -> Em preparo -> Pronto.
- Pode alterar cardápio e disponibilidade pelo painel.

Sem IA:
- Não usa OpenAI.
- Não usa OPENAI_API_KEY.
- Não consome créditos de IA.

Render:
- npm install
- npm start
- Variáveis recomendadas: ADMIN_PASSWORD e PUBLIC_BASE_URL.

IMPORTANTE:
Esta versão é adequada para DEMONSTRAÇÃO. O armazenamento atual usa arquivo JSON do servidor.
Antes de entregar para operação comercial permanente, use banco/armazenamento persistente para pedidos e cardápio.
